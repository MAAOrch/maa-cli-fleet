## 二、问题归类与解决办法

### 1. 凌晨 04:00 国服跨日强制同步弹窗（本次 `emu=31 / 40 / 42` 集中中招）
* **现象**：每天 `04:00 CST` 服务器跨日刷新，局内弹出全屏提示 **`数据已更新，即将进行同步`**（部分伴随 `等待重新连接中.`）。MAA 的 `StrongholdProtocolTaskPlugin` 无法在局内处理该弹窗，只能干等 12 分钟触发 `STALL WATCHDOG (rc=13)` 才重启，既浪费时间又消耗 `--max-retries` 重试次数（如 `emu=40` 已耗到第 3 次重试）。
* **解决办法**：
  1. **即时恢复**：点击同步弹窗确认（或重启游戏走 `StartUp` 自动过每日签到弹窗）再重进 `个人模拟 → 极速模拟`。
  2. **长期根治**：
     * 在 `tools/spa_badge_runner.py` 轮询中增加对 `04:00` 日切同步/长时间卡顿的识别，或在 `spa_batch_runner.py` 里将 `04:00–04:15` 窗口内触发的 `rc=12/13` 视为「跨日重登」**不计入 `max_retries` 消耗**，直接重走 `StartUp` 过签到后无缝续刷。
     * 同时在 `config/maa/MAAOrch/spa_cn.json` 的 `ClosePopup` 中补充 `数据已更新` / `确定` 兜底点击。

### 2. 已终止局的「断线重连」卡死大厅（历史问题，已根治）
* **现象**：游戏异常中断且对局已结束时，大厅右下角只显示 **`已终止 / 断线重连`** 而没有 `放弃模拟` 按钮，此时 `个人模拟` 页签无法切换，脚本反复点击 `个人模拟` 死循环。
* **解决办法（已部署 `0dd948c`）**：在 `config/maa/MAAOrch/spa_cn.json` 新增 `MAAOrch@SPA@CN@ReconnectTerminated`，优先检测 `断线重连 / 已终止` 点进结算页再点 `返回主页`，清空残局后自动切回 `个人模拟`。

### 3. 非默认主题导致字体/布局偏移（历史问题，已根治）
* **现象**：账号装备非默认皮肤（如 `乌萨斯齐心团`）时，商店字号与布局变化，导致 MAA OCR 误读回合数、不买不放（0 胜连败）。
* **解决办法（已部署）**：在 `spa_cn.json` 加入 `MAAOrch@SPA@EnsureDefaultTheme`（进大厅 → `更换主题` → 选 `卫戍协议终端` → `设置主题` → 返回大厅），并在 `spa_badge_runner.py` 强制校验 `ArrivedQuickly` 门禁通过后才允许启动 `StrongholdProtocol`。

### 4. 模拟器刚开机时 ADB 未就绪导致 `AsstConnect failed (rc=5)`（历史问题，已根治）
* **现象**：重启模拟器后立刻连 ADB 偶发失败直接退出。
* **解决办法（已部署 `ca289c2`）**：在 `spa_badge_runner.py` 的 `AsstConnect` 前加 `adb connect` 预热 + 3 次重试（间隔 4 秒）。

### 5. 单号调整牵连全批次重启 & AUTO-MAS 冲突浪费资源（历史问题，已根治）
* **现象**：早先撤出单个号必须停掉整个批次连累其他在跑号；AUTO-MAS 只开 1 个不冲突的号时却导致 SPA 5 开全停。
* **解决办法（已部署 `7c18dc9` / `fec1366` / `bc16bbe`）**：
  * 引入按单号共存模式（`SPA + MAS <= concurrency`，仅在 MAS 占用同一 ADB 端口时单号热礼让 `rc=15`）。
  * 引入 `spa_batch_control.json` + Web UI「单停 / 热加 / 热改并发」，调整单个号零重启、不打扰其他在跑账号。
